# Deenly.uz — Arch D

The user selected **Arch D**. This is the only active logo direction.

- `01-arch-d.png`: original generated reference, retained for brand history.
- `frontend/src/shared/ui/logo/arch-d-path.ts`: production vector geometry.
- `frontend/public/logo/arch-d.svg`: standalone mark.
- `frontend/public/favicon.svg`: adaptive light/dark favicon.

The SVG is a deliberate vector interpretation of the concept: a compact D
silhouette with arch-shaped negative space and a curved lower opening. The UI
uses local Public Sans for the wordmark, avoiding text embedded in a raster.
No sacred text or divine names appear in the logo.

Unused alternatives and the old template branding were removed from active
source and kept only in ignored `runtime/cleanup-20261011/` for recovery.

## Generation brief (summary)

Use case: logo-brand. Create a premium original horizontal logo presentation
for Deenly.uz, a personal Islamic learning platform with a modern minimalist
React MUI interface. Design a solid D monogram with a generous geometric outer
curve and integral mihrab-like arch carved into negative space. Use deep emerald
#087F6F for the mark and dark charcoal #142D2A for the contemporary humanist
sans-serif wordmark. Exact text: `Deenly.uz`, once, without a tagline. Plain white
background, flat vector-like design, balanced optical spacing, scalable clean
silhouette. No sacred text, divine names, stock crescent/star icons, minarets,
domes, ornate calligraphy, patterns, gradients, shadows, metallic effects, 3D,
watermarks, mockups or additional alternatives.
